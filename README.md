# Сервер Rocket Visuals

Один сервер на Render делает всё:

- **косметика:** игроки видят мечи и шляпы друг друга;
- **ключи:** активация, дни, привязка к компьютеру;
- **версии мода:** установщик скачивает последнюю;
- **панель владельца:** `https://rocket-visuals-sync.onrender.com/admin`.

Ключи и версии мода хранятся в бесплатной базе **Neon**, потому что бесплатный Render стирает файлы при перезапуске.

В этой папке три файла для хостинга: `RocketSyncServer.java`, `admin.html`, `Dockerfile`.

## 1. База Neon (один раз)

1. Зайди на https://neon.tech, нажми **Sign up** и войди через GitHub.
2. Создай проект (**Create project**):
   - имя любое, например `rocket-visuals`;
   - Postgres версию не меняй;
   - регион ближе к Render, например **AWS Europe (Frankfurt)**.
3. На главной странице проекта нажми **Connect**. Скопируй строку подключения (**Connection string**).
   Она выглядит так: `postgresql://neondb_owner:....@ep-....neon.tech/neondb?sslmode=require`.
   **Никому её не показывай**: с ней можно менять ключи.

## 2. Файлы на GitHub

1. Открой репозиторий `beisov2013-hue/rocket-visuals-sync`.
2. Нажми **Add file → Upload files** и перетащи три файла из этой папки:
   `RocketSyncServer.java`, `admin.html`, `Dockerfile`.
3. Нажми **Commit changes**.

## 3. Настройки на Render

1. Открой https://dashboard.render.com, затем свой сервис `rocket-visuals-sync`, затем слева **Environment**.
2. Нажми **Add Environment Variable** и добавь две переменные:
   - `DATABASE_URL`: строка из Neon (шаг 1.3);
   - `ADMIN_PASSWORD`: придумай пароль для панели, минимум 8 символов. Тоже никому не показывай.
3. Нажми **Save, rebuild and deploy**. Подожди, пока статус станет **Live**.

## 4. Проверка

1. Открой `https://rocket-visuals-sync.onrender.com/admin` и войди своим паролем.
2. На вкладке **Версии мода** загрузи `.jar` мода (например, версия `1.0.1`).
3. На вкладке **Ключи** создай ключ на 1 день и активируй его в установщике.

## Как пользоваться панелью

- **Новые ключи:** укажи дни, количество и заметку (кому продал). Скопируй ключ и отправь покупателю.
- **+7 / +30 / ±…:** продлить ключ или убрать дни. Если ключ уже истёк, продление считается от сегодня.
- **Отвязать ПК:** игрок сменил компьютер. Срок сохраняется, ключ можно активировать заново.
- **Отключить:** мод у игрока выключится при следующем запуске игры.
- **Версии мода:** загрузи новый `.jar`. Все установщики поставят его при следующем запуске.

## Запуск у себя (для проверки)

```
java -cp postgresql.jar RocketSyncServer.java 8765
```

Без `DATABASE_URL` работает только косметика.
